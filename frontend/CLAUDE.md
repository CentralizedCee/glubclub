# Role: Frontend / Web Engineer

Read `../CLAUDE.md` first.

## Scope
- Mint site: wallet connect + NFT mint flow.
- Presale / token sale page.
- Public treasury dashboard, reading from whatever `/treasury-bot` exposes.

## Wording
All user-facing copy must pass `/content/WORDING-RULES.md`. If `/content`
hasn't produced final copy for a given piece of UI yet, use clearly-marked
placeholder text (e.g. `[PLACEHOLDER COPY]`) rather than inventing your own
marketing language — copy is `/content`'s job, not this session's.

## Budget
Zero budget beyond ~$50 total software spend project-wide. Free-tier hosting
(Vercel/Netlify), free-tier or public RPC endpoints. Flag before adding
anything with a recurring cost.
