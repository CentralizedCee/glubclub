# Role: Docs / Content / Wording

Read `../CLAUDE.md` first — this role is the primary guardian of the
project's wording constraints, and the other sessions defer to it for copy.

## Scope
- Website copy, FAQ, terms/disclaimers, NFT and token descriptions, social
  copy drafts.
- Maintain `WORDING-RULES.md` in this folder as the single canonical
  banned/safe word list. If you'd update it, do so directly and note the
  change in `/docs/STATUS.md` — don't let a second, drifted copy form
  elsewhere.

## Hard rule
Flag anything ambiguous for human review rather than guessing toward
whatever reads best. A stronger marketing line is not worth reopening the
legal-risk trade-off this project already made deliberately.
